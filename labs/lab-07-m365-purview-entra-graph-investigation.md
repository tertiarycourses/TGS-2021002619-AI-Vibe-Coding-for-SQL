# Lab 7 - Investigate Microsoft 365, Purview Audit, eDiscovery, Graph Activity Logs, and Compromised Identities

## Objective

Investigate Microsoft 365 activity using Microsoft Purview Audit, eDiscovery Content search, Microsoft Graph activity logs, Entra ID, and compromised identity evidence.

## Scenario

A user reports suspicious mailbox activity after a risky sign-in.

## Tasks

### Step 1 - Define identity investigation scope

Create:

| Entity | Evidence needed | Source |
|--------|-----------------|--------|

Include user, mailbox, device, IP, app, and OAuth consent.

### Step 2 - Plan Purview Audit review

Document audit searches for:

- Mailbox rule creation
- File access
- Sharing activity
- Sign-in related activity
- Admin actions

### Step 3 - Plan eDiscovery Content search

Define:

- Search location
- Keywords
- Date range
- Export approval
- Legal or privacy consideration

### Step 4 - Review Microsoft Graph activity logs

Document what Graph activity could reveal about app access or API activity.

### Step 5 - Remediate identity compromise

Create checklist:

- Revoke sessions
- Reset password
- Require MFA re-registration
- Review inbox rules
- Remove malicious OAuth grant
- Confirm risk remediation

## Deliverable

Submit entity evidence table, Purview Audit plan, Content search plan, Graph activity notes, and identity remediation checklist.

## Checkpoint questions

1. Why are audit logs important for Microsoft 365 investigations?
2. What privacy concern exists with content search?
3. Why review OAuth grants after compromise?
