# Lab 5 - Investigate Defender XDR Incidents, Case Management, Multi-Stage Attacks, and Security Copilot

## Objective

Investigate Defender XDR incidents, manage cases, analyze multi-stage attacks, and use Security Copilot or agentic AI prompts responsibly.

## Scenario

A phishing email leads to a risky sign-in and suspicious endpoint activity. The SOC must triage and document the incident.

## Tasks

### Step 1 - Build incident timeline

Create:

| Time | Event | Source | Entity |
|------|-------|--------|--------|

### Step 2 - Identify affected entities

List:

- User
- Device
- Mailbox
- IP address
- File
- URL
- Cloud app

### Step 3 - Investigate by workload

Document evidence from:

- Defender for Office 365
- Defender for Endpoint
- Defender for Cloud Apps
- Microsoft Entra ID
- Defender for Identity
- Microsoft Sentinel

### Step 4 - Use AI investigation prompts

Write prompts such as:

```text
Summarize this incident timeline and identify the most likely initial access vector.
```

### Step 5 - Manage the case

Define severity, owner, status, remediation actions, and closure criteria.

## Deliverable

Submit timeline, entity list, workload evidence table, AI prompt list, and case management notes.

## Checkpoint questions

1. Why should incidents be investigated across workloads?
2. What should be verified before trusting AI summaries?
3. What makes an incident ready to close?
