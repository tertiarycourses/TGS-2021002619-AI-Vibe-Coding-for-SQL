# Lab 6 - Respond to Endpoint Incidents with Device Timeline, Live Response, Evidence, and Investigation Packages

## Objective

Investigate Defender for Endpoint incidents using device timeline, live response, evidence, entity investigation, and investigation packages.

## Scenario

A device alert shows suspicious script execution and possible credential theft.

## Tasks

### Step 1 - Review device timeline

Create:

| Timestamp | Event | Process | Account |
|-----------|-------|---------|---------|

### Step 2 - Identify evidence

Document:

- Process
- File
- Registry item
- Network connection
- User account
- Related alert

### Step 3 - Plan device actions

Create:

| Action | When to use | Approval required |
|--------|-------------|-------------------|

Include isolate device, collect investigation package, run antivirus scan, restrict app execution, and live response.

### Step 4 - Write live response plan

Document commands or actions to collect:

- Running processes
- Network connections
- Suspicious files
- Event logs

### Step 5 - Remediation checklist

Include containment, eradication, recovery, user communication, and lessons learned.

## Deliverable

Submit device timeline, evidence table, action plan, live response plan, and remediation checklist.

## Checkpoint questions

1. Why is device isolation powerful but disruptive?
2. What evidence should be preserved before remediation?
3. When should live response be used?
